 1. Материнская плата — основа компьютера, которая объединяет все компоненты.
  Процессор - главный 'мозг'компьютера отвечающий за обработку информации.
  Оперативная память - это быстрая временная память устройства, работает при включенном компьютере.
  Долгосрочная память - сохраняет всё даже после выключения компьютера.

  2. Под стек область памяти выделяется под каждый процесс, а по завершении процесса данные из стека пропадают. Для кучи же нет ограничений по размеру, она одна для всей программы, и там хранятся любые данные, которые могут динамически увеличиваться в объёме. 

  3. Примитивные и ссылочные.

  4. Примитивные типы хранят своё значение в стеке и имеют строгое ограничение по размеру. У ссылочных типов нет строгого ограничения по памяти, и они могут динамически увеличиваться во время выполнения программы. 

  5. Переменная - это имя области памяти, предназначенное для хранения данных определенного типа во время выполнения программы.

  6. ! — отрицание (Отрицание возвращает обратное значение) 
  & — логическое умножение (Логическое сложение и умножение используется с двумя логическими переменными. Умножение будет истинно, если обе переменные истинны, в остальном результат будет ложный.) 
  | - логическое сложение (Сложение будет ложно, если обе переменные ложны. В остальных случаях будет истинно.)
